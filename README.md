# 🚀 Futuristic Calculator

![Calculator Preview](https://github.com/AnanyaSinghBabu/Calculator/blob/main/image.png)

This project contains **two versions** of a fully featured calculator:

1. **Web Application** – Built with **FastAPI** and **HTML/CSS/JS**.
2. **Desktop GUI Application** – Built with **Tkinter**.

---

## ✨ Features

* ➕➖✖️➗ **Basic Operations:** addition, subtraction, multiplication, division.
* 🧮 **Advanced Functions:** square root, exponentiation, percentage, pi constant.
* 💾 **Memory Functions:** MC, MR, M+, M-.
* 🔄 **Sign Toggle (+/-).**
* 🎨 **Modern & Responsive UI** – clean design for both web and desktop.

---

## ⚡ How to Run

### 🌐 Web Application

1. **Install dependencies:**

   ```bash
   pip install fastapi uvicorn python-multipart
   ```

2. **Run the server:**

   From the `calculator` directory, run:

   ```bash
   uvicorn main:app --reload
   ```

3. **Open in browser:**

   Navigate to:

   ```
   http://127.0.0.1:8000
   ```

---

### 🖥️ Desktop GUI Application

1. **Run the application:**

   From the `calculator` directory, run:

   ```bash
   python gui.py
   ```

   ✅ The calculator window will appear.
